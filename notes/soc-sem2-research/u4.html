Normal distribution and significance

The normal distribution

Shape and properties

  • The normal distribution is a symmetric, bell-shaped curve.
  • It is centred around the mean.
  • The mean, median, and mode are equal.

Standard normal distribution

  • A normal distribution with mean = 0 and standard deviation = 1.
  • Any normal distribution can be converted using z-scores.

z-score formula

  • z = (X − μ) / σ
  • X = individual score
  • μ = population mean
  • σ = population standard deviation

Empirical rule

  • 68% of data falls within ±1 SD of the mean.
  • 95% falls within ±2 SDs.
  • 99.7% falls within ±3 SDs.

Hypothesis testing

Null and alternative hypotheses

  • Null hypothesis (H0): states there is no effect, no difference, or no relationship.
  • Alternative hypothesis (H1): states there is an effect, difference, or relationship.
  • Research tries to find evidence against the null hypothesis.

Significance level (alpha)

  • The probability of rejecting the null hypothesis when it is actually true.
  • Common values: 0.05, 0.01, 0.001.
  • A smaller alpha means stronger evidence is required.

p-value

  • The probability of obtaining the observed results if the null hypothesis were true.
  • If p < alpha, the result is statistically significant.
  • If p > alpha, we fail to reject the null hypothesis.

Type I and Type II errors

Decision H0 is true H0 is false
Reject H0 Type I error (false positive) Correct
Fail to reject H0 Correct Type II error (false negative)
  • Type I error: saying there is an effect when there is not.
  • Type II error: missing an effect that is real.

One-tailed and two-tailed tests

One-tailed test

  • Predicts the direction of the effect.
  • Example: "Group A will score higher than Group B."

Two-tailed test

  • Predicts a difference but not the direction.
  • Example: "Group A and Group B will differ."

When to use

  • Use one-tailed only when theory strongly predicts direction.
  • Two-tailed tests are more common and conservative.

t-test

Purpose

  • Compares the mean of one group to a known value, or the means of two groups.

Types

  • One-sample t-test: sample mean vs known population mean.
  • Independent samples t-test: means of two unrelated groups.
  • Paired samples t-test: means of the same group measured twice.

Assumptions

  • Data are approximately normally distributed.
  • Variables are measured at interval or ratio scale.
  • Observations are independent.

Exam checklist

  • Normal distribution: symmetric, bell-shaped, mean = median = mode.
  • z-score: how many SDs a value is from the mean.
  • H0 = no effect; H1 = predicted effect.
  • Alpha = probability of Type I error; p < alpha = significant.
  • Type I error = false positive; Type II error = false negative.
  • t-test compares means.
