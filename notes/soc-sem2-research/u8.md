# Personality tests

## Key Topics
- Self-report inventories ask respondents to rate statements about themselves.
- Examples: MMPI, NEO-PI, Eysenck Personality Questionnaire.
- Projective techniques present ambiguous stimuli to reveal unconscious traits.
- Rorschach Inkblot Test: interpret symmetrical inkblots.
- Thematic Apperception Test (TAT): create stories from pictures.
- Sentence Completion Test: finish incomplete sentences.
- Projective tests are flexible but scoring can be subjective.

## Definitions
- **Self-report inventory**: questionnaire measuring personality traits.
- **Projective technique**: ambiguous stimulus used to uncover inner feelings.
- **MMPI**: Minnesota Multiphasic Personality Inventory.
