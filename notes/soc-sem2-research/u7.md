# Intelligence testing

## Key Topics
- Intelligence tests measure cognitive abilities such as reasoning, memory and problem-solving.
- Stanford-Binet Intelligence Scales: individual test with IQ score (MA/CA × 100).
- Wechsler tests: WAIS for adults, WISC for children, WPPSI for preschoolers.
- Wechsler uses deviation IQ comparing score to age-group norms.
- Culture-fair tests (e.g. Raven's Progressive Matrices) reduce language/cultural bias.
- IQ distribution follows normal curve; mean = 100, SD = 15.

## Definitions
- **IQ**: intelligence quotient.
- **Mental age (MA)**: age level of performance.
- **Chronological age (CA)**: actual age in years.
- **Culture-fair test**: minimises cultural and linguistic bias.
